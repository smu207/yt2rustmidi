유튜브 링크가 있다면

웹페이지는 보안 정책 때문에 유튜브에서 직접 소리를 받아올 수 없습니다. 링크를 넣으면 내 컴퓨터에서 실행할 다운로드 명령을 만들어 드려요. 받은 mp3 파일을 위에 놓으면 됩니다.

처음 한 번은 pip install yt-dlp 와 ffmpeg 설치가 필요합니다. 권리가 있는 곡이나 개인 학습 용도로만 사용하세요.

옵션

4트랙은 기타·피아노·신스가 "기타 악기" 한 트랙에 함께 들어갑니다. 편집기의 트랙 나누기로 정리할 수 있어요.

긴 곡은 메모리를 많이 쓰니, 처음에는 30~60초 구간으로 시험해 보세요.

진행 상황 

    첫 실행 때 분리 모델(4트랙 약 170MB, 6트랙 약 136MB)을 한 번 내려받습니다. 이후에는 브라우저에 저장된 모델을 씁니다.

    결과

    변환이 끝나면 악기별 소리와 MIDI 파일이 여기에 나옵니다.

    분리: Demucs(HTDemucs / HTDemucs 6s, MIT) · 음표 변환: Spotify Basic Pitch(Apache-2.0). 모든 계산은 이 브라우저 안에서 이루어지고 파일은 어디에도 올라가지 않습니다.

    트랙 역할

    편집기에 열린 곡으로 만듭니다. 잡음을 먼저 정리해 두면 결과가 깔끔해져요. 드럼은 솔로곡에 넣지 않습니다.

    연주할 러스트 악기

    악기별 음역은 공식 자료에 나와 있지 않아 추정값입니다. 아래 테스트 파일을 게임에서 재생해 소리가 나는 가장 낮은·높은 음을 확인한 뒤 숫자를 맞춰 주세요. 테스트 파일은 C 음을 길게 쳐서 옥타브를 세기 쉽게 했습니다.

    편곡 방식

    결과

    옵션을 고르고 솔로곡 만들기를 누르세요.

    러스트에서 재생하기

    1. Steam에서 Rust → 관리 → 로컬 파일 보기를 열고, Rust.exe 옆에 instruments 폴더를 만듭니다.
    2. 저장한 솔로 MIDI 파일을 그 폴더에 넣습니다.
    3. 게임에서 악기를 들거나 피아노에 앉아 F1 콘솔을 열고 아래 명령을 입력합니다.
    instruments.playrecording solo_song

    키에 묶어 두려면 bind n instruments.playrecording 파일이름 처럼 입력하세요. 파일 이름에 공백이나 한글이 있으면 명령이 안 될 수 있어 영문·숫자·밑줄을 권장합니다.

    트랙 클릭해서 편집할 트랙 선택

      트랙 다듬기 현재 트랙

      섞인 트랙(예: 기타 악기)에서 한 악기의 음표만 골라 새 트랙으로 옮기세요. 고르는 방법:

      C4 ~ C6 · Shift를 누른 채 누르면 지금 선택에 더합니다. 피아노 롤에서 드래그로 직접 골라도 됩니다.

      잡음 의심 음표

      0개 · 현재 트랙
      앞뒤로 이 시간 안에 다른 음이 하나도 없으면 의심합니다. 0이면 끕니다.
      MIDI 음 번호입니다. 60 = C4(가운데 도).
